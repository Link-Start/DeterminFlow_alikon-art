# 统一账户公开资料

Core 使用账户服务的 `GET /api/desktop-auth/profile` 获取当前公开资料。网站仅向固定账户源站
`GET /oauth/userinfo` 转发 Bearer 凭据，Portal 校验有效会话及 `profile:read` 后返回 `sub` 和 `name`。
资料请求不依赖模型服务的权限或余额，不向资源广场页面暴露访问或刷新令牌。

Core 只在返回的 subject 与当前账户一致时接受笔名；退出或切换账户会清除缓存，并阻止旧响应写入。
资料在内存中缓存 5 分钟，失败后 30 秒内不重复请求；失败时可回退到当前登录凭据携带的名字。
明确返回空名字时保留空值，不重新显示过时名字。

账号状态及资源广场状态接口按需触发资料获取。多个请求共用一次获取，单次状态响应最多等待 4 秒；
后台 HTTP 请求仍有独立超时。状态请求超时或取消不会取消已经开始的刷新令牌轮换。
资料查询失败不直接清除有效登录状态；401 后沿用统一账户的续期机制。

网站发布表单继续只为未填写、未手动编辑的作者署名填入账户笔名。作者已经编辑的署名不会被异步
资料更新覆盖。远端资料接口尚未部署时无法保证真实笔名可用，不能用演示名字冒充账户资料。
